# 素材库商品关联减负

一次素材查询会读取商品列表，并对每条素材扫描全部商品；原来返回筛选结果时还会再查一次同品牌商品。建立按商品 ID 的本次请求索引，保留数据库返回的原始商品顺序和去重语义；同次请求共享一次商品查询。采集作品归一化复用一个无状态分析对象。不改变素材筛选、跨来源全局排序、总数、返回字段、品牌边界及数据库内容。

回归覆盖商品顺序/重复/缺失、产品过滤、一次查询、数据库不可用时不发商品查询及原有素材能力。8000 条素材、2000 个模拟商品的处理结果前后 SHA-256 一致；重复测量样本耗时下降。8000 条素材、67 个模拟商品时收益较小，结果哈希仍一致。以上均为合成数据，不能说明任意电脑的实际端到端速度或峰值内存。

此版本没有将多个来源截断分页：原片、关系和总数的完整性仍优先。服务端跨来源全局分页、真实负载、资源上限和长期压力测试留待后续验证。没有删除 Ontology、3Chat 渠道绑定、有赞店铺绑定或其历史数据。
