# 设计图片自动登记与电商展示

设计工作台生成成功后，受控存储内的本品牌本任务图片自动登记为 MediaAsset，供电商执行器按任务找到并关联主图或详情页；图片不重新生成。仅接受本服务、当前品牌、当前任务的受控路径；远程外链不冒充受控素材。已存在同任务同对象的记录不重复登记。登记异常只记录告警，不能把已发生的付费生成当作可安全重试。

历史失败任务需核对生成回执、项目版本、图片存储与实际解码后，使用中台素材登记和项目版本保存逻辑恢复，不改写失败历史。无源文件或项目版本不一致时停止恢复，不自动调用供应商。

公开本地版与 SaaS 副本同步；本轮无真实新增生图，历史恢复与真实后续生图是两种不同验证。跨服务偶发登记错误、远程供应商直链和超过素材列表窗口的情况仍应按原产物查证。
