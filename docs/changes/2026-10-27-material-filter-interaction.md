# 素材筛选交互减负

镜头的 SKU、场景、动作、景别、表面输入在停止输入 350 毫秒后再查询，连续输入合并为一次；选择筛选条件时同步回到第一页，避免先请求旧页码再请求第一页。只显示最新一次请求的结果和错误，较慢的旧响应不会覆盖新结果。

本地模拟页面交互验证：第二页选择商品仅产生一次第一页查询，连续输入 `abc` 产生一次包含 `abc` 的查询，较慢的图片请求不会覆盖后发的视频请求，输入未完成时清空条件不恢复旧输入。模拟页面使用虚拟品牌和数据。前端生产构建通过。

该改动不改变后端筛选规则、数据及权限，也没有实现服务端查询取消或跨来源分页；它减少连续输入和翻页切换引起的多余请求，不代表所有场景或设备都已流畅。
