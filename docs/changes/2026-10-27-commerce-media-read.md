# 电商工作区媒体读取减负

电商详情工作区只需媒体及创作素材的标识、标题、类型、存储路径和媒体任务引用。查询改为选择这些字段，避免读取完整媒体元数据和素材正文；数据库原始记录不变。仍先按原规则取最近 200 条再过滤无存储路径的记录，避免意外改变显示范围。

四品牌详情工作区完整响应一致；运营工作区对照仅有每次调用生成的检查时间不同，排除此时间后其余一致。合成测试覆盖跨品牌、媒体地址、缺少存储路径和 200 条边界。一个品牌的 35 条媒体记录在应用侧 JSON 序列化约 20.7 MB 降至 9 KB，单次整工作区候选对照约 244 ms 降至 4 ms；这不是完整请求或整机内存的长期测量。

执行 `npm run build:server` 和 `node scripts/test-commerce-media-projection.cjs`，并验证电商详情、任务及独立环境隔离；实际用户业务与低配置长期运行仍需验证。
