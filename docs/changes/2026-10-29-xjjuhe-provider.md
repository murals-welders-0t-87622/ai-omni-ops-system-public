# 鸭屎香聚合平台接入

平台地址 `https://xjjuhe.site`，接口参考 https://xjjuhe.site/docs/quickstart 和 https://xjjuhe.site/docs/openai。品牌在智控中心为此平台自行配置 API Key，代码不含凭据。

提供 OpenAI 兼容对话模型配置（默认草稿）、GPT Image 2/2.5 异步图片生成和 Omni 10 秒视频生成。图片提交后用任务编号查询，视频优先使用平台返回的 `id` 查询；提交结果不明或查询失败时不自动再次提交，以免重复计费。视频当前仅支持横屏和竖屏，参考图需要平台可访问的公网直链。平台其他模型、视频解析、商品解析、音频及数字人能力没有因本次配置自动接入。

七项模拟测试和后端编译不代表供应商真实联调或实际费用验证；需要客户在自己的品牌配置凭据、核对模型授权后另行验证。更新源码不会自动更新正在运行的实例。
