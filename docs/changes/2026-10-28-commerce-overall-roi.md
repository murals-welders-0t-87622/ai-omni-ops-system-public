# 电商经营目标：整体 ROI 与计划广告费

本轮为经营目标增加可选的目标整体 ROI（倍）和只读计划广告费：计划广告费＝全店支付 GMV ÷ 目标整体 ROI，按元四舍五入到分。整体 ROI 为全店支付 GMV / 广告费，区别于广告平台按广告归因成交计算的 ROI，也不代表利润率。输入的 ROI 为经营目标，不是历史实际数据。

重排任务携带 ROI 和计算结果；服务端检查输入及结果中选中方案的广告投入一致，并将目标保存到方案版本元数据。ROI 改变时，执行器不得复用旧目标的草稿。旧版三字段目标仍可使用，无需数据库迁移。无 ROI、ROI 不大于零或无效时不计算费用；无效值不能提交重排。
