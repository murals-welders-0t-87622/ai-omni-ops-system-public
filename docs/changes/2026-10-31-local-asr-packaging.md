# 本地视频文案提取候选修复

旧新机指令默认关闭本地 ASR，且旧构建使用的模型缓存挂载不会自动进入镜像；依赖和模型需要分别验证。新机安装技能源码改为默认启用，Dockerfile 将模型复制到 server 镜像并在构建时尝试离线加载，前端不复制模型；依赖下载增加缓存和有界重试。构建模型及运行模型应相同，默认 small。

当前仅源码候选，隔离构建在模型阶段因 Docker 连接中断，未完成离线模型或真实视频验收，未发布。新机不得据此声称功能已就绪；已有实例升级须先核备份、数据、密钥、在途任务与回退，不能通过重新初始化或删除卷修复。详情及安装时检查见配套技能的 Windows Docker 手册。

后续将模型复制改为独立脚本，只复制选定快照；在虚构缓存和受限 Linux 容器分别验证离线查找及安全处理软链接，未验证真实模型和语音识别。安装技能修改尚在本地源码，未同步到已安装版本或公开仓库。

新增轻量检查脚本区分组件不可导入、离线模型缺失和基础文件不完整；文件存在不证明模型可加载或语音可识别。用户仍需在自己正在运行的实例按安装技能分层验收；未发布的新脚本并不自动进入旧容器。
