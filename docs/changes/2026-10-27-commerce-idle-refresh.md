# 电商工作区空闲刷新减负

电商详情页以往即使没有任务也每 5 秒刷新整个工作区。现在排队或运行任务时仍每 5 秒刷新，空闲时每 60 秒刷新；切回可见页面会立即检查，隐藏页面不轮询。一次后台读取未结束时不再叠加请求，手动刷新仍可进行。

对未保存文案，开始编辑后返回的旧后台读取不会覆盖草稿；品牌或工作区切换仍沿用现有作用域检查。页面发起任务后，服务返回带任务状态的工作区，立即进入快速刷新。其他客户端启动的任务在空闲状态下会在下次刷新、切回页面或手动刷新时发现，最长可能等待约一分钟。

本地使用模拟数据测试了空闲/运行/完成频率、慢请求不叠加、隐藏/返回页面和未保存草稿保护；前端生产构建通过。实际网络延迟、负载及低配置长期使用仍需验证。
