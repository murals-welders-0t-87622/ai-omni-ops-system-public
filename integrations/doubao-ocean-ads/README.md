## 交付结构

- `partner-profile.md`：原生工作伙伴的名称、简介、角色指令、连接器/技能清单与开场提示。它是配置稿，不是豆包已支持的JSON导入格式。
- `package/ocean-ads-operations/`：独立方法Skill，含运营方法、连接器路由、中台契约、报告模板和离线参数准备脚本。
- `source-manifest.json`：10个研究来源、版本及文件hash；研究副本留本机，不放入可分发ZIP。
- `tests/`：离线参数校验及分页/幂等/品牌范围测试。
- `dist/`：仅自主编写的伙伴配置和方法Skill；无凭据、真实广告数据或社区付费实现。

## 验证与限制

运行 `python -m unittest discover -s tests -v`。离线脚本只准备MCP参数，不联网、不读取密钥、不提交数据。真实广告查询、归档回读、原生伙伴列表和新会话加载分别登记；离线通过不等于业务联调通过。

千川现有接口以账户聚合为主，商品/人群/搜索词/素材明细须实时接口确有能力或用户提供合法导出，不能倒推或伪造。仅有期间聚合而没有日明细时先保留原表，不伪造成日快照。中台现有分页、快照、诊断、计划修订已能承接核心流程，本轮不新增重复工作区或投放写操作。
