会话343补充：isolated-profile.cjs仅准备品牌×连接独立的配置/记忆/工作区/状态/日志目录，不复制桌面认证，不启动Agent。新client配置必须匹配manifest、连接名和品牌，且manifest明确ready/automaticExecutionEnabled；未授权拒绝启动。仅原brand-demo-cleaning固定旧连接兼容历史模式。当前运行中336实例未替换，仍为旧单品牌配置；准备工具测试不等于新品牌客户端授权、模型可用或真实执行。

仅限独立 Ontology Lab、显式配置的连接器和品牌。宿主常驻进程每15秒查询已授权队列；空队列不会启动模型。WorkBuddy随包CLI使用既有模型配置，独立工作区、专家包、会话、严格MCP代理和全工具PreToolUse守卫。当前默认模型配置来自本轮桌面已有的ark-code-latest，不修改全局默认模型或专家启用偏好。

`node worker.cjs <private-config.json>` 启动；`--once`只检查一批。配置不含密钥，指向既有WorkBuddy连接器；代理在父进程读取现有凭据，不传给模型。示例字段见本轮安装脚本，实际config仅保存在源码外受限Lab运行目录。不可指向原系统130xx或其他品牌。

执行分为：队列发现→独立会话→实际技能读取→正式团队/成员工具调用→同源提交→独立MCP读回。启动/心跳不是专业成功；只有提交回执、计划版本及真实成员工具证据同时存在才标完成。计划保持draft，建议保持待决定；后台不自动生效、采纳、填经营数、发文、花费或触达。

MCP代理只暴露所选planId/checkId及必要品牌读取。文件守卫限制工作区和只读专家包；任何未列工具均拒绝，包含PowerShell/Bash/外部搜索/图片视频生成/其他连接器。原生CLI可能仍在初始工具列表里展示默认工具，守卫和代理是实际执行门禁，不能仅凭`--tools`列表判定限制成功。

本机日志在运行目录，保留实际stream、元数据observed、提交回执和完成记录。不要把完整日志或凭据复制进源码。失败保留原委托和尝试，30分钟冷却、最多3次；暂停/结束由中台即时拦截。并发用进程锁；发现残留运行进程拒绝重复启动。CLI及适配升级须再次验证真实行为，不盲目套用新版在线文档。

测试：`node --test tools/workbuddy-growth-executor/test.cjs`。安装和回退见会话336开发存档。当前Windows任务计划注册受ACL拒绝，已使用当前用户Startup快捷方式与隐藏启动脚本；实际重启登录恢复尚未实测，关机或未登录时不运行。取消/暂停现有增长计划不等于删除专家方法或全局自动化。
